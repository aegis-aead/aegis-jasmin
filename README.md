# AEGIS implementation in Jasmin

A high-performance, high-assurance implementation of the [AEGIS-128L, AEGIS-128X2, AEGIS-256, and AEGIS-256X2](https://www.rfc-editor.org/info/rfc10032/) ciphers for x86_64 CPUs with AESNI in the [Jasmin](https://github.com/jasmin-lang/jasmin) programming language.
